# Правила выдачи и жизни токенов

Реализовано в `AuthService` (`src/MyApplication/MyApplication.Application/Auth/AuthService.cs`).

## Пользователь

Создаётся при первом входе через Google, идентифицируется по
`GoogleSubjectId` (идентификатор профиля Google — не email, чтобы смена
email в Google-аккаунте не создавала второго пользователя). При каждом
повторном входе email и имя обновляются свежими данными из профиля Google.

## Access token

- JWT, подписанный сервером (HMAC-SHA256, ключ — конфигурация
  `Jwt:SigningKey`, не Google).
- Срок действия — 15 минут по умолчанию (`Jwt:AccessTokenLifetimeMinutes`).
- Передаётся клиентом в заголовке `Authorization: Bearer <token>`.
- Содержит идентификатор пользователя (`sub`), email и имя.

## Refresh token

- Случайная строка (не JWT), хранится на сервере в виде SHA-256 хэша — сырое
  значение нигде, кроме момента выдачи клиенту, не сохраняется.
- Срок действия — 30 дней.
- Веб-клиент хранит его в httpOnly/Secure/SameSite=Strict cookie, скоуп —
  только на `/Auth` (см. [контракт API](./api-contract)); недоступен
  клиентскому JS.
- **Ротация**: каждый `POST /Auth/refresh` отзывает использованный refresh
  token и выдаёт новый — повторное использование уже отозванного токена
  считается невалидным (`InvalidRefreshTokenException`, 401).
- У одного пользователя может быть несколько одновременно активных refresh
  token'ов (по одному на сессию/устройство) — они хранятся как отдельные
  записи, а не единым полем на пользователе, специально ради поддержки
  нескольких параллельных клиентов (веб, в будущем — мобильный).

## Нарушение правил

- Невалидный/просроченный/выданный не для этого приложения Google ID token
  → `InvalidGoogleTokenException` → `401`.
- Отсутствующий/просроченный/уже отозванный refresh token → `InvalidRefreshTokenException` → `401`.
- Отсутствующий/невалидный access token на защищённом эндпоинте (например,
  `/Notes`) → `401` (проверяется JWT bearer middleware ещё до контроллера).
- Валидный access token, но обращение к чужому ресурсу (например, к чужой
  заметке) → `403`, см. [«Заметки»](/notes/overview).
