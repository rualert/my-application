# Контракт API

## Запрос

```
GET /WeatherForecast
```

Без параметров, без аутентификации.

## Ответ

`200 OK`, тело — JSON-массив из пяти объектов:

```json
[
  {
    "date": "2026-09-17",
    "temperatureC": 22,
    "summary": "Cool",
    "temperatureF": 71
  }
]
```

| Поле | Тип | Описание |
|---|---|---|
| `date` | `string` (`YYYY-MM-DD`) | Дата, на которую построен прогноз |
| `temperatureC` | `int` | Температура, °C. См. [правила формирования](./business-rules) |
| `summary` | `string \| null` | Текстовое описание погоды |
| `temperatureF` | `int` | Температура, °F (вычисляется из `temperatureC`) |

## Ошибки

Явных бизнес-ошибок сценарий не порождает — реализация не содержит проверок
входных данных (запрос без параметров) и не обращается к внешним системам,
которые могли бы отказать.
