# Прогноз погоды — обзор

## Что это

Сценарий возвращает прогноз погоды на ближайшие дни. Это **демонстрационная
функция**, оставшаяся от стандартного шаблона ASP.NET Core Web API
(`dotnet new webapi`) — сам код так и помечен комментарием «тестовый метод,
который делает хоть что-то». Реального источника данных о погоде нет: значения
генерируются случайным образом при каждом обращении.

Раздел описан здесь не потому, что это важная бизнес-функция, а чтобы
зафиксировать текущее поведение приложения и задать пример структуры
документации для будущих, уже настоящих, сценариев.

## Где реализован

| Слой | Компонент | Ответственность |
|---|---|---|
| Application | `IWeatherForecastService` | Порт (контракт use case'а) |
| Application | `WeatherForecastService` | Реализация — генерация прогноза |
| Application | `WeatherForecast` | Модель прогноза на одну дату |
| Api (Presentation) | `WeatherForecastController` | HTTP-обёртка над use case'ом |
