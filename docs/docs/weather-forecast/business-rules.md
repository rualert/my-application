# Правила формирования прогноза

Реализовано в `WeatherForecastService.GetForecasts()`
(`src/MyApplication/MyApplication.Application/WeatherForecasts/WeatherForecastService.cs`).

## Период прогноза

Прогноз строится ровно на **5 дней вперёд**, начиная с завтрашнего дня
(текущая дата на сервере + 1 … +5 дней включительно). Прошлые даты и сегодняшний
день в прогноз не входят.

## Температура

Для каждого дня температура в градусах Цельсия — случайное целое число в
диапазоне **от −20 до 54 включительно** (генерируется как `Random.Next(-20, 55)`,
верхняя граница не включена).

Температура в Фаренгейтах не хранится отдельно, а вычисляется из Цельсия по
формуле:

```
TemperatureF = 32 + (int)(TemperatureC / 0.5556)
```

## Текстовое описание погоды

Для каждого дня случайно выбирается одно значение из фиксированного списка
из 10 вариантов (без учёта фактической температуры — описание и температура
никак не связаны между собой):

```
Freezing, Bracing, Chilly, Cool, Mild, Warm, Balmy, Hot, Sweltering, Scorching
```

## Детерминированность

Прогноз **не детерминирован**: значения температуры и описания генерируются
заново при каждом вызове (`Random.Shared`), два последовательных запроса
почти наверняка вернут разные данные для одних и тех же дат.
